# Builds vending machine: finish-quality brief

Create a polished, original engineering-workshop vending machine inspired by the coherent world-building and considered presentation of Jesse Zhou's Ramen portfolio. Retain Kavish's blue, cream, brass and warm workshop palette, existing projects and direct links.

## Visual finish
- Make the cabinet read as a manufactured object: coherent frame, shelves, lighting, fasteners, selector hardware and collection opening. Give surfaces restrained wear and a clear hierarchy, keeping project labels legible.
- Refine each project miniature as a recognisable, connected assembly. Use the Strata photographs and CAD reference for its layered acrylic body, chassis and tyres; do not claim a photo-based reconstruction is a scan. Keep the quadcopter, orbit display and wing understandable at cabinet scale and in close-up.
- Light and frame the scene so materials, forms and silhouettes are visible without obscuring the navigation or project copy.

## Interaction and movement
- The selected shelf spiral turns, advances its object inside the glass, and releases it into a clear drop lane. The object reaches the collection opening before moving into a consistent close-up beside the project information.
- Keep the object on screen and slowly rotate it while the user reads. Switching projects, going back, opening project links, reducing motion, resizing and leaving the section should not strand an animation or duplicate objects.
- Provide visible controls and usable keyboard access; keep project details available if WebGL fails.

## Quality and performance checks
- Inspect every selection, including the motion, shelf clearance, collection hatch and close-up, with repeated selection and return. Check console errors and the existing automated tests.
- Pause rendering while off-screen or hidden; keep geometry, shadows and textures economical, and honour reduced motion. Do not claim photogrammetry, authored-asset parity or benchmark gains without evidence.
