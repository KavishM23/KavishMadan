# MP4/4 model attribution

“McLaren-Honda MP4/4” by [Flamestroke](https://sketchfab.com/Flamestroke), [original model](https://sketchfab.com/3d-models/mclaren-honda-mp44-27e1406278ba4293b065b6220ef4eb93), is licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). The model is adapted in the website: wheels are separated for animation.

The body wordmarks are sharpened using the wordmark paths extracted from [Marlboro Logo.svg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Marlboro_Logo.svg), identified there as a public-domain text logo.

## Project machine models (assets/models/vending)
Original work for this site. Strata uses the team's own CAD. Globe coastlines come from Natural Earth 1:50m (public domain) through the world-atlas package (ISC). Plaque lettering uses Blender's built-in font. See the README in that folder for what is real and what is inferred.

The workshop scene (assets/models/vending/workshop) is original. Its method follows Jesse Zhou's published case study on baked three.js scenes, and none of his assets are used. Labels in prints.webp are rasterised from macOS system fonts.

## Code stairwell (assets/models/code)
Original work for this site, built from the scripts in `src/`. Set dressing, including the food, books, chairs and arcade cabinet, is invented for the scene. Project screens are the real apps. The drone is the same representative model as the vending machine quadcopter, not a replica of a real prototype. Labels are rasterised from macOS system fonts, and the chalkboard shows TutorTime's real match formula.
